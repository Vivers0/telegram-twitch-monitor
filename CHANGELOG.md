# Changelog

Все значимые изменения этого проекта документируются в этом файле.

## [Unreleased]

### Added
- Команда `/addall` — авторизация через Twitch (OAuth) и добавление всех каналов, на которые подписан пользователь, в список отслеживания.
- Фоновая синхронизация подписок Twitch (по умолчанию раз в 5 минут, настраивается через `FOLLOWS_CHECK_INTERVAL`): при появлении новой подписки бот присылает сообщение с инлайн-кнопками «Да / Нет» для добавления канала в отслеживание.
- Автоматическое обнаружение отписок на Twitch: канал удаляется из списка отслеживания, пользователю приходит уведомление.
- Поддержка нескольких файлов окружения с приоритетом: `.env` → `<NODE_ENV>.env` (например, `development.env`) → `local.env`.
- Валидация обязательных переменных окружения при старте — при отсутствии токенов или `TWITCH_REDIRECT_URI` бот завершается с понятным сообщением об ошибке.
- Эндпоинт `GET /health` для проверки состояния сервиса (Docker healthcheck, мониторинг).
- Корректное завершение по `SIGINT`/`SIGTERM`: остановка таймеров, Telegram-бота и HTTP-сервера.
- Переменная окружения `DB_PATH` для настройки расположения файла базы данных.

### Changed
- Проект разбит на модульную структуру `src/` (config, db, twitch, bot, jobs, server) вместо одного монолитного `index.js`; `index.js` в корне остался тонкой точкой входа, запуск не изменился.
- App-токен Twitch кэшируется до истечения срока действия вместо перевыпуска на каждом цикле проверки стримов.
- ID каналов Twitch кэшируются после первого резолва — меньше запросов к API на каждый цикл.
- Проверка стримов группируется по каналу: один запрос к Twitch на канал независимо от числа подписчиков; уведомление о старте стрима получают все подписанные чаты, а не только первый.
- Prepared statements SQLite создаются один раз при старте; включён режим `journal_mode = WAL`.
- Обновлена справка `/start` — добавлено упоминание `/addall`.
- Из логов убраны учётные данные прокси (раньше `PROXY_URL` с логином и паролем выводился в консоль целиком).

### Fixed
- Повторные ложные уведомления «стрим начался»: ошибка запроса к Twitch API (например, таймаут прокси) трактовалась как «стрим закончился», из-за чего после восстановления связи уведомление отправлялось заново. Теперь при ошибке статус считается неизвестным и кэш не сбрасывается.
- Дублирование уведомлений при медленной сети: циклы `setInterval` накладывались друг на друга, если проверка длилась дольше интервала. Добавлена защита от параллельных запусков для обоих фоновых циклов.
- Ложная «массовая отписка»: при сбое запроса списка подписок бот получал пустой/неполный список и удалял все каналы из отслеживания с потоком уведомлений. Теперь при ошибке API цикл синхронизации пропускается без изменений данных.

### Security
- OAuth `state` для `/addall` генерируется криптографически случайно (вместо предсказуемого `chatId_timestamp`), одноразовый, с временем жизни 10 минут — защита от подделки колбэка и привязки Twitch-аккаунта к чужому чату.
